## 5. INFEKTIONSZEICHEN — NERDS / STONEES

### 5.1 NERDS-Kriterien (lokale Infektion — ≥3 Kriterien positiv → V.a. lokale Infektion)

```
☐ N — Nonhealing (keine Heilungstendenz trotz adäquater Therapie ≥14 Tage)
☐ E — Exudate (zunehmende Exsudatmenge)
☐ R — Red/friable granulation (leicht blutendes, brüchiges Granulationsgewebe)
☐ D — Debris (Beläge, avitales Gewebe im Wundbett)
☐ S — Smell (unangenehmer Geruch)

Anzahl positiver Kriterien: ___ /5
Beurteilung: ☐ Keine lokale Infektion    ☐ V.a. lokale Infektion
```

### 5.2 STONEES-Kriterien (systemische Ausbreitung — ≥3 Kriterien → V.a. Spreading/systemische Infektion)

```
☐ S — Size (Wunde wird größer)
☐ T — Temperature (erhöhte lokale/systemische Temperatur)
☐ O — Os (freiliegender Knochen, Probe-to-Bone positiv)
☐ N — New breakdown (neue Wundareale, Satellitenläsionen)
☐ E — Exudate (deutlich vermehrtes Exsudat)
☐ E — Erythema/Oedema (zunehmende Rötung/Schwellung >2cm um Wundrand)
☐ S — Smell (zunehmender/fötider Geruch)

Anzahl positiver Kriterien: ___ /7
Beurteilung: ☐ Keine systemische Ausbreitung    ☐ V.a. Spreading/systemische Infektion
```


## HINWEISE ZUR ORBIS-INTEGRATION

Diese Vorlage ist so strukturiert, dass die einzelnen Abschnitte als **strukturierte Textbausteine** in ORBIS übernommen werden können:

1. **Abschnitte 1–4:** Entsprechen dem ABCD-Schema und können als Pflegebericht-Eintrag strukturiert werden
2. **Abschnitt 5 (NERDS/STONEES):** Eigener Dokumentationsbaustein für Infektionsbeurteilung
3. **Abschnitt 6 (DFS):** Eigener Baustein, nur bei DFS-Verdacht relevant
4. **Abschnitte 8–9:** Therapieplan-Baustein
5. **Abschnitt 11:** Verlaufsbaustein mit Wiedervorlagedatum

**WundScan AI-Export:** Die App kann die KI-Analyseergebnisse in dieses Format überführen. Manuelle Felder (Anamnese, Durchblutung, Unterschriften) müssen durch die dokumentierende Fachkraft ergänzt werden.
