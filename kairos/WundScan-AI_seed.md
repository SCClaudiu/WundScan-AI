# WundScan-AI – Seed für Kairos Wissensbasis
Erstellt: 2026-04-01

## Projektübersicht
WundScan-AI ist ein KI-gestütztes System zur Analyse, Dokumentation und Unterstützung von Wundheilungsprozessen.

## Technischer Stack
- Programmiersprache: Python
- KI-Modell: Claude 3.5 Sonnet (Anthropic API)
- Agent: Kairos Daemon (proaktiver Background-Agent)
- Vector Database: ChromaDB
- Versionskontrolle: Git
- Überwachung: GitHub Issues & PRs

## Aktueller Stand
- Kairos Daemon läuft
- GitHub-Integration mit SCClaudiu/WundScan-AI ist aktiv
- Memory-System (ChromaDB + autoDream) ist im Aufbau

## Ziele
1. Aufbau einer stabilen Langzeit-Wissensbasis
2. Proaktives Monitoring von Issues und Code-Änderungen
3. Automatische Refactoring-Vorschläge
4. Stabile Fehlerbehandlung

Kairos soll dieses Projekt langfristig begleiten, Code verbessern und bei der Weiterentwicklung helfen.
