# WundScan-AI v5.0.0

Pflegerisches Wunddokumentationssystem fuer den klinischen Einsatz.

## Starten

1. **Doppelklick** auf `WundScan-AI-Start.bat`
2. Browser oeffnet sich automatisch auf http://localhost:8082
3. CMD-Fenster offen lassen (Server laeuft dort)

## Beenden

- CMD-Fenster schliessen (Strg+C)
- Oder `WundScan-AI-Stop.bat` ausfuehren

## Voraussetzungen

- Windows 10/11
- Python 3.x (muss im PATH sein)
- Moderner Browser (Chrome, Edge, Firefox)

## Funktionen

- Patientenverwaltung
- Wunddokumentation mit Foto
- Wundverlauf
- AI-Analyse (lokal oder API)
- Dunkelmodus
- Export/Import als JSON
- DSGVO-konform (alle Daten lokal im Browser)

## Hinweis

Die App MUSS ueber den lokalen Server gestartet werden.
Direktes Oeffnen der HTML-Datei (file://) wird NICHT unterstuetzt.
